# Getting started in this Repo

This file provides guidance on how an agent should work and interact with the human when completing tasks in this repository. Do not skip these steps — they define how you are expected to work here.

## Step 1
Read `rules-of-engagement.md` and follow it for the rest of the session (including any START_TOKEN it defines). Acknowledge that you have understood its contents and what it is trying to achieve. Follow the content of the document to evidence this. 

## Step 2 
Read the repository's `README.md` for project-specific conventions, commands, and constraints.

## Step 3
If you want to remember things in the next session, add a file with a date and time stamp to a directory called /memory, please create it if it doesn't exist. Always read the most recent file first, then any subsequent memory files as required.
